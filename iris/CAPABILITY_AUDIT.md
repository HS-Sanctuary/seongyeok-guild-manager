# MM AI 에이전트 읽기 범위 점검 (2026-09-28)

근거: 이 PC에서 `MabinogiMobile_CLI.exe capabilities`가 반환한 28개 명령과 읽기 전용 명령의 실제 응답 구조. 게임/운영 DB 데이터는 변경하지 않았다. **명령 목록에 없다는 사실은 현재 CLI에서 직접 제공되지 않는다는 뜻이지, 게임 전체에 해당 정보가 없다는 뜻은 아니다.**

| 한설 요청 | 현재 판정 | 근거·한계 |
| --- | --- | --- |
| 닉네임 | 직접 조회 미확인 | `get_my_info`에는 이름 필드가 없다. `RealmName`은 데이안 서버명이다. 주변 플레이어 조회를 자신의 신원으로 오인하지 않는다. |
| 초상화 | 직접 조회 미지원 | 현 CLI 명령·기본 정보에 이미지 URL/바이너리/초상화 필드가 없다. 별도 화면 캡처는 현재 읽기 계약에 포함하지 않는다. |
| 전투력·생활력·매력·마도저항·데코점수 | 확인됨 | `get_my_info`에서 실측했다. 데코점수도 로컬 화면에 추가했다. |
| 은동전·마족 공물 | 확인됨 | `get_currencies`의 정확한 표시 이름과 보유량을 읽어 로컬 화면에 추가했다. |
| 어비스·레이드·필드보스 | 주간 횟수만 확인됨 | `get_weekly_missions`의 목표·현재 횟수·완료 여부. 콘텐츠별 이름이나 과거 클리어 이력은 나오지 않는다. `get_activity`의 던전 상태는 현재 진행 상태일 뿐 과거 기록이 아니다. |
| 길드공헌도 | 직접 조회 미지원 | `get_my_info` 및 재화 목록에 공헌도 필드가 없다. `길드 토큰` 잔액은 공헌도와 동일시하지 않는다. |
| 장착 룬 | 직접 조회 미지원 | 장비/룬 조회 명령이 없고 `get_items` 설명은 소모품류만 포함하며 장비는 제외한다. |
| 랭킹 | 직접 조회 미지원 | 순위·랭킹 조회 명령이 없다. 생텀 자체 랭킹과 별개다. |
| 나이트메어 드릴 최고층 | 직접 조회 미지원 | 전용 기록 조회 명령이 없고 일/주간 미션에도 최고층 정보가 없다. |
| 크로노스 상점 구매·물물교환·임무 게시판 완료 | 직접 조회 미지원 | 구매/교환/게시판의 기간별 완료 이력 명령이 없다. 보유 아이템이나 현재 퀘스트만으로 완료를 역산하면 오판 위험이 있다. 생텀의 기존 수동 체크를 유지한다. |

다음 안전한 경로: 게임 CLI가 새 읽기 명령을 제공할 때 기능 목록과 응답을 재점검한다. 닉네임·초상화·완료 내역은 별도 공식 데이터 경로가 확인되지 않으면 사용자가 생텀 계정·캐릭터를 직접 선택하는 방식으로 연결한다. 이미지/화면 인식으로 보완하려면 정확도·개인정보·배포 범위를 별도 검증한다.
