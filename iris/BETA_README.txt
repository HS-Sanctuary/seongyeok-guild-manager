IRIS for SANCTUM — Windows x64 베타 후보

1. ZIP 전체를 원하는 폴더에 압축 해제한 뒤 IRIS.exe를 실행합니다.
   관리자 권한, Node.js, 개발 서버는 필요하지 않습니다.
2. 대부분의 PC에서는 추가 설치 없이 실행할 수 있습니다. 내장 화면은
   Microsoft Edge WebView2 Runtime을 사용하며 Windows 11에는 기본 포함되고
   대부분의 Windows 10에도 이미 설치되어 있습니다. 없다는 오류가 날 때만
   https://developer.microsoft.com/microsoft-edge/webview2/ 에서 설치합니다.
   IRIS는 런타임이나 게임 도구를 자동 설치하지 않습니다.
3. 생텀 계정으로 로그인합니다. 기본 브라우저의 로그인은 공유하지 않습니다.
   이 패키지는 운영 생텀에 접속하므로 웹 기능은 운영 배포 상태를 따릅니다.
4. 게임 정보 읽기는 기존 마비노기 모바일 공식 생활 커넥터와
   MabinogiMobile_CLI.exe를 그대로 사용합니다. 이미 사용하는 커넥터/게임을
   다시 설치하지 않습니다. 게임/CLI는 동봉하지 않습니다.
   기본 위치: C:\Nexon\MabinogiMobile\MabinogiMobile_CLI.exe
   다른 위치는 MABINOGI_CLI_PATH 환경 변수로 지정한 뒤 IRIS를 재실행합니다.
5. 계정·홈·설정은 캐릭터 선택줄 오른쪽, 최소화·종료는 제목 오른쪽입니다.
   업데이트 전에는 기존 IRIS를 정상 종료하세요. 대기 기록을 임의로 지우지 마세요.
   앱의 보호 대기함과 전용 로그인은 본인 Windows 사용자 AppData에 저장됩니다.

주의: 아직 코드 서명되지 않은 소규모 베타 후보입니다.
다운로드 또는 실행 시 Windows/보안 프로그램 경고가 표시될 수 있습니다.
출처와 SHA-256이 확인되지 않은 파일은 실행하지 마세요. 백신/방화벽을 끄거나
보안 정책을 낮출 필요는 없습니다. 실행이 차단되면 관리자 한설에게 알려주세요.
다른 PC의 설치·DPI·게임 창 위치 및 장시간 동작은 별도 검증이 필요합니다.
Microsoft WebView2 라이선스와 고지 사항은 동봉된 파일을 참고하세요.

베타 제한: 일부 길드버스 회차 완료/해산/관리자 인계와 이전 요청 확인에는
기존 확인창 경로가 남아 있습니다. 버튼에 반응이 없으면 생텀 웹
https://sanctum-tawny-three.vercel.app/party 에서 처리합니다.
같은 요청을 반복해서 보내지 마세요. 보호 대기 기록은 삭제하지 않습니다.
