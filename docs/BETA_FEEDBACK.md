## 상태 기준

- `접수`: 아직 원인 확인 전
- `재현`: 영겁 또는 순월이 문제를 확인함
- `진행 중`: 수정 구현 중
- `확인 요청`: 수정 후 한설 또는 테스터의 화면 확인 필요
- `완료`: 배포 및 실제 화면 확인 완료
- `보류`: 베타 범위 밖이거나 기획 결정 대기
