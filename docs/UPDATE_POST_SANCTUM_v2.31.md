## 숙제 기록, 잠깐 모아서 저장해요

크로노스에서 연달아 바꾼 기록은 마지막 수정 후 15초에 모아서 저장합니다. 변경은 화면에 먼저 반영되고, 저장할 내용이 있을 때만 작은 반투명 안내가 나타납니다. 기다리고 싶지 않을 때는 ‘지금 저장’을 눌러주세요. 저장 실패나 확인이 필요한 변경은 성공으로 표시하지 않고 안내합니다.

메인페이지의 캐릭터 숙제 카드에서도 여러 항목을 연속으로 체크할 수 있습니다. 여러 캐릭터의 변경은 각 기록을 구분해 반영하고, 저장 중에 추가로 누른 항목도 놓치지 않도록 정리했습니다. 다른 화면이나 계정으로 이동할 때는 먼저 저장을 마칩니다. 실패하면 변경을 유지하고 다시 저장할 수 있도록 안내합니다.

## 필요한 기능을 더 가깝게

표시할 기능 선택 버튼의 세로 여백을 줄여 내용을 더 빨리 볼 수 있게 했습니다. 상단 도구는 두 줄로 모으고, 계정 메뉴·알림함·정령의 날개는 누른 버튼 가까이에서 열리도록 위치를 바로잡았습니다. 작은 화면에서는 화면 밖으로 넘어가지 않도록 조정합니다.

## 이용 전에 확인해주세요

업데이트가 보이지 않는다면 페이지를 새로고침해주세요. 기록을 바꾼 뒤 화면을 닫기 전에는 저장 상태를 확인해주세요. 이번 업데이트는 기존 캐릭터·숙제 기록을 삭제하거나 권한을 바꾸지 않습니다.

사용하시다가 어색한 부분이 보이면 ‘어느 화면에서 / 무엇을 눌렀는지 / 어떤 일이 있었는지’를 알려주세요. 여러분의 작은 피드백이 생텀을 더 편하게 만듭니다.
