### 먼저 읽을 결론

- **생활 작업을 간단히 실행**하는 방향은 모비 생활 커넥터, **게임 화면에 필요한 정보만 배치·조작**하는 방향은 MoFo, **재고→부족 재료→선행 제작→작업 큐**를 연결하는 방향은 MobiWorks의 근거가 가장 풍부하다. 한 앱이 모든 영역에서 우위인 것은 아니다.
- IRIS는 이 세 앱을 필수 설치 대상으로 삼기보다 공식 CLI를 독립적으로 읽고, 각 앱의 장점을 선택적으로 설계하는 쪽을 권한다. SANCTUM 계정·본인 캐릭터·파티·길드버스 연결은 IRIS의 별도 강점이다.
- 아래 **49항목**은 기존/읽기/로컬/게임 행동/확장/보류·제외를 구분한 체크리스트다. 새 기능 49개가 모두 구현 가능하거나 구현됐다는 뜻이 아니다. 첫 도입 후보는 미션·가공·에린 환경·무게 HUD다.
- 2026-10-11 14:28 KST에 두 제작자 GitHub 최신 릴리스 API를 재대조해 v1.3.1/v1.0.11 및 위 공개 시각을 확인했다. 정상 UI 연결 도구가 실패해 실행 화면 확인은 하지 않았으며, 실행 시 저장된 생활 자동화가 시작될 수 있는 MobiWorks도 무관찰 상태로 실행하지 않았다.

## 2. 현재 IRIS와 비교할 기준

현재 IRIS는 SANCTUM 전용 로그인·선택 캐릭터·보호된 저장 큐를 가진 동반 앱이다. 고정된 공식 CLI 읽기 계약, 본인 스탯 수동 확인 저장, 캐릭터 변경 추천 3초/첫 후보 1초 재확인, 숙제·클래스·재화·물물교환·상점·임무 및 SANCTUM 서버 기반 시낙시스 파티 동선을 이미 사용한다. 외부 도구가 게임 생활 작업을 수행하는 기능과 IRIS가 SANCTUM 기록을 저장하는 기능을 구분한다.

기존 [2026-10-07 검토](IRIS_CONNECTOR_REVIEW_20261007.md)는 사무실에서 게임 커넥터 활성화 뒤 기존 IRIS 읽기가 성공했음을 기록한다. 이는 이번 집 PC에서 모든 기능을 새로 실행했다는 뜻이 아니다. 외부 RAM 도구는 이후 제거 결정이 있으므로 재도입 후보에 넣지 않는다.

## 5. 실제 통합 수단과 권리

**같은 정보의 IRIS 구현**과 **외부 앱에 직접 연결**과 **코드/데이터 재사용**은 서로 다른 선택이다.

- 모비 생활 커넥터는 설치 소스에서 공식 CLI 호출을 확인했다. GitHub는 배포 저장소이며 LICENSE는 확인되지 않았다. 기능 아이디어는 참고할 수 있지만 설치 스크립트·레시피 JSON·EXE의 복사/재배포를 허용한다고 해석하지 않는다.
- MoFo는 README와 제작자 게시물의 표시/조작 기능을 확인했다. 안정적인 HTTP API/파일 export/SDK가 있다는 증거가 없다. 동반 앱 화면을 읽어 API처럼 사용한다고 약속하지 않는다. 배포물 라이선스도 미확인이다.
- MobiWorks는 **로컬 HTTP 경로를 코드에서 확인**했다. `GET /api/work`, `/api/recipes`, `/api/recipes/export`, `/api/queue`, `/api/view/works`, `/api/stats`, `/api/backup` 등이 있으나 인증을 요구하고 일부 조회가 파일을 읽거나 내부 관찰 모델을 갱신할 수 있다. `/api/queue/preview`는 설정에 따라 실제 읽기 CLI를 부르는 경로이며, 모든 GET을 무조건 순수/무영향이라고 간주하면 안 된다. `POST /api/sync`는 게임 조회지만 로컬 캐시를 쓰고, `/api/queue/start`, 폴리오 재생·정지 등은 게임 행동이다. 외부에서 route가 존재한다는 사실만으로 지원되는 IRIS API 계약이 되지는 않는다.
- MobiWorks [LICENSE](https://github.com/Mobi-Lan/MobiWorks/blob/main/LICENSE)는 MIT다. 코드의 사용·변경·배포·판매 권한을 제공하지만 저작권/허가문을 포함해야 한다. 실제 재사용 부분·의존 라이선스를 명시해야 하며, 게임 상표·공식 CLI·사용자 악보·앨범 그림·커뮤니티 기여 데이터의 별도 권리를 자동으로 해결하지 않는다.
- IRIS가 공식 CLI에서 독립적으로 읽으면 다른 앱 설치/업데이트·내부 인증에 덜 묶인다. 동적 포트/토큰을 파일·프로세스에서 몰래 추출하지 않는다. 외부 API를 선택한다면 제작자가 제공하는 사용자 승인 연결·버전 고정 계약부터 필요하다.

## 6. 정보 정확도·운영 위험

1. **출처 범위**: MobiWorks의 레시피 모델은 현재 관찰, seed, community를 합치는 구조다. 소스는 `complete=False`와 충돌/출처별 재료를 구분한다. 관찰이 풍부해져도 게임 전체 레시피·미해금 콘텐츠·최신 변경까지 완전하다는 뜻은 아니다. 생활커넥터의 오프라인 캐시도 갱신 날짜·사용 허가가 필요하다.
2. **현재값과 누적값**: MobiWorks 원장은 앱이 보낸 실행 명령 기준이며 실패 소모 일부는 추정이다. 계정의 실제 총 소비나 타 앱 소비까지 포함하지 않는다. IRIS 현재 재화 잔액을 누적 원장과 혼합해 DB 이력으로 자동 저장하지 않는다.
3. **불완전 응답**: 퀘스트 빈 응답, 제작 부족재료 빈 배열, 시작 직후 연주시간0, 평면/중첩 활동 필드, 동명 악보·레시피, 익명 이름을 별도 방어해야 한다. MobiWorks [CLI 기술문서](https://github.com/Mobi-Lan/MobiWorks/blob/main/docs/CLI.md)는 제작자의 카탈로그 해석/실측 기록이며 넥슨의 공식 SDK 계약과 동일하지 않다.
4. **여러 앱 동시 실행**: 생활커넥터는 약1.5초로 본인/재화/가공/환경/주변을 순차 조회하고 별도 재고 갱신이 있다. MobiWorks도 자체 잠금·캐시·큐를 가진다. 앱 내부 잠금은 다른 프로그램의 행동을 막지 않는다. IRIS도 캐시 공유·한 번의 로컬 관측·실행 소유권이 필요하며 폴링을 DB 저장으로 연결하지 않는다.
5. **쓰기/정지 경계**: 수령도 게임 이동·상태 변경이다. stop_action은 연주·채집 등 타인의 다른 앱 작업에 영향을 줄 수 있다. 응답을 잃은 실행의 재시도는 중복 소모 가능성이 있으므로 확인 전 자동 재시도하지 않는다. 단일 앱의 합성 테스트만으로 서로의 실행을 안전하게 조정했다고 선언하지 않는다.
6. **원격 접속**: 터널/모바일 실행/방송은 네트워크 노출·세션·기기 권한·서비스 비용이 추가된다. MobiWorks에 해당 방어 코드가 있다는 사실은 독립 보안 감사 완료가 아니다. IRIS 길드 인증과 PC 실행 권한은 따로 검증해야 한다.
7. **업데이트 신뢰**: SHA256 비교는 내려받은 파일이 제공 해시와 같은지 확인할 뿐 작성자 자체의 신뢰를 보장하지 않는다. PSF가 서명한 Python 실행파일도 앱의 Python 코드 전체를 인증하는 서명은 아니다. VirusTotal 0건 또한 무해함/정책 승인의 증명이 아니다.
8. **게임 정책**: [넥슨 AI 커넥터 가이드](https://mabinogimobile.nexon.com/Info/Guide/3545322)는 2026-09-17 게임 기준으로 작성되었으며 조회와 일부 생활/연주 행동을 설명한다. 조회는 날개를 소비하지 않지만 행동 소모·1시간 확인·채팅 승인·불가 영역과 정책 위반 제재 경계가 있다. 타인 캐릭터명·길드명·개별 채팅 전달도 제한한다. 기본 비활성이며 7일간 미사용 시 자동으로 꺼질 수 있으므로 연결 실패 안내에서 게임 설정을 먼저 확인하게 해야 한다. 공식 CLI를 쓴다는 이유로 세 외부 앱이나 IRIS가 넥슨 승인/제재 면제라고 단정하지 않는다. [운영정책 페이지](https://mabinogimobile.nexon.com/Support/Policy)의 동적 세부 조항은 이번 텍스트 도구로 전부 확인하지 못했다.
9. **서명 방식 구분**: MobiWorks의 작성자 서명 메타데이터와 Windows 실행파일 Authenticode는 서로 다른 검증이다. 전자는 자체 키·배포·회전 정책을 안전하게 설계할 수 있지만 Windows의 미서명 경고를 없애는 인증서와 동일하지 않다. 무료 미서명 IRIS 방향을 유지하며 이번 조사로 서명 기능을 추가하지 않았다.

## 7. 권장 순서와 남은 확인

현재 베타에서는 **미션·가공·에린 환경·무게를 읽어서 보여 주는 HUD**가 첫 묶음이다. 현재 IRIS와 가장 가까워 기존 저장/캐릭터 추천을 재사용할 수 있다. 그다음 재고·레시피 사전/계산·알림·백업을 묶고, 게임 행동은 수령부터 독립적으로 설계·승인·실기 검증한다. 큰 생활 작업 큐·게임 음악 플레이어·모바일 원격 실행·방송은 베타 핵심 안정화 뒤의 확장 후보다.

미확인: MoFo 최신 버전/릴리스·소스·라이선스, 생활커넥터 스크립트/레시피 재사용 허가, MobiWorks 커뮤니티 데이터별 권리, 각 앱의 현재 게임 호환·장시간/DPI·동시 실행 안정성, 공식 외부 SDK 지원 여부. 이 항목들을 미확인으로 남겨도 공개 버전·기능별 구현 근거·우선 도입 목록은 검토할 수 있다.

공개 페이지는 web 도구로 우선 검색했다. 아카라이브 원문과 일부 GitHub/제작자 사이트는 fetch 제한이 있어, 설치 source에 명시된 정확한 공개 URL만 PowerShell의 HTTPS 읽기로 대조했다. 내려받은 설치 프로그램을 저장/실행하지 않았고 비공개 설정·로그·토큰 파일은 읽지 않았다. 조사 중 검색에 나온 동명 MobiWorks 기업은 대상에서 제외했다.
