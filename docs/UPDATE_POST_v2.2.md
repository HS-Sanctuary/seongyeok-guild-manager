# SANCTUM BETA v2.2 업데이트 안내

작성자: SANCTUM 시스템
작성일: 2026-10-10 KST
상태: 사용자용 업데이트 노트 / 공개 게시하지 않음

이번 업데이트는 시낙시스 길드버스를 편하게 운영할 수 있도록 개선했어요.

- 생성할 때 적은 공지가 컨텐츠 변경 후 기본 문구로 돌아가는 문제를 수정했어요.
- 버스 관리자가 컨텐츠·난이도·공지·날짜/시간과 자기 계정의 참가 캐릭터를 다시 수정할 수 있어요. 8인에서 4인으로 바꾸어도 기존 참가자는 삭제되지 않고 대기열에 남아요. 다른 계정의 신청 시간과 반복 설정, 숙제 기록은 유지돼요.
- 접속 중인 참가자는 버스 설정이 바뀌면 알림을 받을 수 있어요. 알림을 누르면 해당 버스로 이동해요.
- 현재 신청 시간과 완료·반복 상태를 반영해서 서로 다른4/8계정이 준비되면 해당 관리자에게만 **“길드버스 출발 가능합니다!”**를 알려요. 자동으로 출발하지는 않아요.
- 버스 목록은 가까운 예정일과 빠른 시작 시간 순으로 보여요.
- 파티 가입이나 버스 생성/가입에서 캐릭터 닉네임을 누르면 생텀에 저장된 레이드·어비스 완료 상태를 확인할 수 있어요. 캐릭터 참가 선택은 별도 선택칸으로 해 주세요.

새로고침 후 이용해 주세요. 시낙시스 알림을 꺼 둔 계정에는 해당 알림이 오지 않아요. 접속 전의 변경이나 이미 준비된 버스는 소급해서 알리지 않으며, 브라우저가 절전 상태면 시간 기준 알림이 늦어질 수 있어요. 공지가 이미 기본값으로 저장된 버스는 관리자가 다시 입력해 주세요.

물물교환 즐겨찾기 연동과 IRIS 후속 변경은 이번 배포에 포함하지 않았어요.
