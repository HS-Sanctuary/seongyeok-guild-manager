이 버전부터는 더 새로운 지원 버전이 있을 때 제목줄의 Beta 버전 옆에 강조된 **업데이트 버튼**이 나타나요. 버튼을 누르면 IRIS 안에서 내려받고 파일을 확인한 뒤, 변경 내용을 보호 대기함에 보관하고 앱을 다시 시작해요. 따로 다운로드 페이지를 찾지 않아도 돼요.

새 앱이 정상적으로 시작되지 못하면 이전 앱 파일을 복원하도록 만들었어요. 게임·커넥터·로그인 프로필·보호 대기 기록은 앱 파일 교체 대상이 아니에요. **다운로드가 시작된 뒤에는 중단 버튼을 제공하지 않으니 준비됐을 때 진행해 주세요.**

생텀 상단 IRIS 로고 버튼에서 언제든 다운로드 안내를 찾을 수 있어요. 업데이트 소식은 이 글에 모아두고, 새 버전마다 이 브라우저에서 계정별로 한 번 안내해 드려요. 밝은 테마와 어두운 테마에서도 같은 흐름으로 사용할 수 있어요.

## 🚀 시작은 네 단계예요

1. **AI 커넥터 켜기** — 마비노기 모바일 인게임 **설정 → 게임** 탭에서 **“마비노기 모바일 AI 커넥터 beta”**를 켜주세요.
2. **압축 풀기** — 다운로드한 ZIP을 폴더에 **모두** 압축 해제해 주세요.
3. **IRIS.exe 실행** — 압축을 푼 폴더 안에서 실행해 주세요. 업데이트 전 기존 IRIS는 정상 종료해 주세요.
4. **생텀 로그인** — IRIS에서 생텀 계정으로 따로 로그인하고 캐릭터를 선택해 주세요. 기본 브라우저의 로그인은 공유하지 않아요.

## 🛡️ 사용 전 잠깐 확인해 주세요

IRIS는 **Windows x64용 무료·미서명 베타**예요. 필요한 구성 요소가 이미 있는 PC에서는 별도 설치 없이 ZIP을 풀고 실행할 수 있어요. 구성 요소가 없다는 오류가 있을 때만 안내 페이지의 공식 설치 링크를 확인해 주세요. 이미 사용하는 공식 커넥터를 다시 설치할 필요는 없고, 게임이나 CLI는 IRIS 다운로드에 포함하지 않아요.

Windows 보안 경고나 실행 차단이 나타날 수 있어요. 출처와 안내 페이지의 파일 확인값을 확인하고 실행 여부를 선택해 주세요. **보안 프로그램을 끄거나 차단을 억지로 우회하지 마세요.** 이상이 있으면 사용을 멈추고 한설에게 알려주세요.

일부 브라우저에서 **“조직에서 차단함”**이라는 다운로드 차단 안내가 확인됐어요. 이 경우 다운로드·실행을 멈추고 한설 또는 해당 PC의 정책 담당자에게 알려주세요. 정확한 차단 원인은 확인 중이며, 미서명 때문이라고 단정하거나 보안 설정을 해제하는 방법을 안내하지 않아요.

일부 길드버스 운영·이전 요청 확인창은 아직 IRIS에서 연결이 남아 있어요. 버튼이 반응하지 않으면 **생텀 웹 시낙시스에서 처리**하고 같은 요청을 반복해서 보내지 말아 주세요. 다른 PC·화면 배율·장시간 사용 검증도 계속 진행 중이에요. IRIS가 게임을 대신 조작하거나 보상을 수령하지는 않아요.
