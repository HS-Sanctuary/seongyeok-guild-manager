## 작게 접어두고, 필요한 순간에 펼쳐요

제목 오른쪽의 □로 작은 바로 접고 펼칠 수 있습니다. 작은 바를 옮겨둔 위치는 메뉴를 열어도 유지하고, 긴 내용은 패널 안에서 스크롤합니다. 게임을 최대화하면 작은 바로 바뀌고, 일반 창으로 돌아오면 설정한 왼쪽·오른쪽 연동을 다시 따릅니다. 게임 최소화·복원과 다른 프로그램 뒤로 가는 동작도 함께 정리했습니다.

## 내 눈에 편한 아이리스

창 양쪽 가장자리로 가로 폭을 직접 조절할 수 있습니다. 글자 크기는 6~22pt, 글꼴은 이 PC에 설치된 목록에서 검색해 선택합니다. 투명도는 30~100%로 조절하며 100%는 선명하게, 30%는 뒤가 많이 비칩니다. 테마와 표시 설정은 이 PC에서 기억하고, 다른 사람이나 웹의 표시 설정을 바꾸지 않습니다.

## 캐릭터를 바꿔도, 기록은 신중하게

접속한 캐릭터의 클래스·스탯을 기존 기록과 비교해 가까운 후보를 추천합니다. 추천은 신원 확인이 아니므로 직접 확인한 뒤 선택해주세요. 다른 캐릭터를 고를 때는 같은 카드 선택창을 사용하고, 연필 버튼으로 닉네임·주클래스를 수정하거나 대표 캐릭터를 설정할 수 있습니다. 빈 칸 대신 ‘캐릭터 추가’ 카드 하나를 표시합니다.

## 놓치기 쉬운 시간, 알림으로 알려드려요

크로노스의 ‘알림’에서 필드보스·소환의 결계·어비스 구멍·심층 구멍 안내를 확인합니다. 콘텐츠별 알림과 짧은 벨 소리를 따로 켜고 끌 수 있고, 처음에는 켜져 있습니다. 어비스의 예상 시각과 승인된 제보를 구분하며, 심층의 정기 제보 초기화를 확정 출현으로 알리지 않습니다. 구멍 정보는 생텀 제보를 이용합니다.

## 저장과 종료도 더 분명하게

미저장 변경이 있으면 ‘생텀에 저장 후 종료’와 ‘이 PC에 보관 후 종료’를 구분해 안내합니다. 이 PC에 보관한 변경은 다른 PC로 전달되지 않습니다. 게임 종료 때도 저장 상태를 먼저 확인하며, 재화는 조회만 하고 생텀 DB에 저장하지 않습니다.

## 업데이트 방법과 주의사항

기존 아이리스의 업데이트 안내를 확인해주세요. 업데이트 조회에 실패하는 구버전은 정상 종료한 뒤 다운로드 페이지의 최신 ZIP 전체로 교체해야 합니다. 베타 앱은 아직 서명되지 않았으며, 조직·보안 프로그램이 차단하면 임의로 보안 설정을 낮추지 말고 운영진에게 알려주세요.

아이리스는 게임 조작이나 보상 수령, 메모리 정리를 하지 않습니다. 외부 도구 이용에 관한 게임사의 판단을 보장하지는 않으므로 이용 정책도 함께 확인해주세요. 실제 게임·다른 해상도에서 남은 문제가 보이면 알려주시면 다음 개선에 반영하겠습니다.
