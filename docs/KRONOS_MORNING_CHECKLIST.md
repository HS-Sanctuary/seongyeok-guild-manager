## SQL의 영향과 복구

- 신규 테이블 4개와 진행률 함수 1개만 추가한다. 기존 계정·캐릭터·물물교환 행 및 기존 RLS 권한은 변경하지 않는다.
- `nexus_trades`는 확인된 실제 컬럼명을 그대로 사용한다. 기존 `nexus_purchases`·`nexus_missions`는 컬럼·제약이 확인되지 않아 변경하거나 삭제하지 않는다. 새 기능은 `kronos_shop_items`·`kronos_missions`를 쓴다. 기존 테이블 데이터를 자동 복사하지 않는다.
- 실제 상점 품목·가격·임무 보상 목록은 제공받지 않았으므로 임의의 게임 데이터를 운영 SQL에 넣지 않았다. 관리자 화면에서 등록한다.
- SQL은 트랜잭션이며 재실행 가능하다. 중간 오류 시 전체가 롤백된다. 오류 전문에서 비밀값을 제외하고 알려준다.
- 적용 후 앱 문제가 생기면 운영 코드는 `db06f7e`를 기준으로 복구할 수 있다. 추가한 테이블은 그대로 남겨도 기존 코드에 영향을 주지 않으며, 메모·진행 데이터를 보존하기 위해 삭제하지 않는다.

## 동작 규칙

- 크로노스 상위 탭 6개는 다중 선택. 0개 선택은 전체 표시, 표시 순서는 항상 왼쪽 탭 순서다. 임무 내부의 마을 탭은 제거했다.
- 임무는 캐릭터별, 매주 월요일 06:00 **Asia/Seoul** 초기화. 북마크·메모는 초기화하지 않는다.
- 상점은 골드, 물물교환은 아이템 소모. 두 카탈로그 ID와 진행 기록을 섞지 않는다.
- 리마인드는 두 슬롯의 **비모달 창**이다. 다른 숙제를 클릭해도 닫히지 않는다. X 또는 해당 창에서 Escape로 닫는다. 제목줄 방향키로 이동할 수 있고, 모서리 크기 조절 및 크기 복원을 제공한다.
- 저장 중 창 편집·중복 저장을 막으며 오류 시 초안을 유지한다. 메모는 본인 계정 서버 경로로만 읽고 쓴다.
