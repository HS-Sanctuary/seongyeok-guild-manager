## 공개 전 순서

1. 한설이 최근 백업 확인 후 `supabase/migrations/20260924_logos_private_report_images.sql` 실행 성공을 보고했다. `supabase/diagnostics/20260924_logos_images_verify_readonly.sql`에서 `attachment_column_exists`, `reporter_account_column_exists`, `private_bucket_ready`는 true, `anon_can_read_inquiries`, `authenticated_can_insert_inquiries`는 false로 확인했다. 백업 시각은 독립 확인 전이다.
2. 변경 묶음을 diff·보안 리뷰 후 Preview 배포한다. 일반 계정 글/사진 작성과 본인 재조회, 다른 일반/부마스터 계정의 타인 제보 접근 거부, 길드마스터 목록·답변·사진 확인을 실제 계정으로 시험한다. 비밀 코드나 개인정보가 담긴 화면은 시험 사진에 사용하지 않는다.
3. 기존 베타 핵심 동선(로그인·가입 승인, 캐릭터 숙제 저장, 공지, 파티, 문의)을 Preview에서 재확인하고 Production으로 배포한다. Ready 후 실제 운영 화면을 다시 확인해 업데이트 노트에 남긴다.
4. 사진의 보존 기간과 계정 탈퇴/추방 시 정리·익명화 원칙을 한설과 정한다. 현재 새 글 삭제 UI는 없고, 사진을 포함한 글은 자동 삭제되지 않는다.

실패 시 새 코드만 단독으로 이전 버전으로 되돌릴 수는 있지만, 이미 저장된 사진 경로/버킷은 즉시 삭제하지 않는다. 백업·첨부 목록·접근 차단 상태를 확인한 뒤 별도로 정리한다.
