# 생텀 폐쇄 베타 이용 가이드 — 게시 원고

이 문서는 길드원용 `생텀 가이드` 게시를 위한 원고다. 현재 게시판의 해당 분류는 링크형이므로 운영 게시물로 등록되기 전까지는 사이트에 노출되지 않는다.

SANCTUM은 성역 길드원 전용 베타 서비스입니다. 로그인 후 본인의 캐릭터와 길드 활동을 확인해 주세요. 사용 중 궁금한 점이나 잘못된 내용이 보이면 언제든 길드마스터 또는 운영진에게 알려주세요.

- **생텀 홈:** 오늘의 길드 정보와 주요 현황을 한눈에 확인합니다.
- **케리그마:** 공지와 생텀 안내를 읽습니다. 중요한 새 소식은 이곳에서 확인해 주세요.
- **크로노스:** 캐릭터를 관리하고 일일·주간 숙제, 물물교환, 상점 구매와 임무 진행 상황을 기록합니다. 저장 완료 표시를 확인한 뒤 페이지를 이동해 주세요.
- **아고라:** 길드원 현황과 각종 순위를 확인합니다.
- **시낙시스:** 파티를 찾고 참여하거나 모집합니다.
- **로고스:** 1:1 문의와 생텀 버그 제보·건의사항을 남깁니다. 제보·건의는 작성자 본인과 길드마스터만 볼 수 있으며, 접속 코드나 비밀번호는 적지 마세요.
- **엠포리온·그노시스:** 현재 개발 중입니다. 화면의 예시 가격이나 자료는 실제 거래·확정 공략으로 사용하지 마세요.

불편을 알려줄 때는 ‘어느 화면에서 / 무엇을 눌렀는지 / 어떤 일이 일어났는지’만 적어도 괜찮습니다. 화면 사진이 있으면 로고스의 버그 제보에 첨부할 수 있습니다. 베타 기간에는 기능과 화면이 바뀔 수 있으며, 운영진이 길드원들의 의견을 살펴보겠습니다.
