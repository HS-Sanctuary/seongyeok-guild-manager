## 1. 한 문장 목표

마비노기 모바일 PC 플레이 중 게임을 벗어나지 않고 SANCTUM의 크로노스 숙제와 시낙시스 파티를 확인·조작하며, **본인이 허용한 자기 캐릭터 정보만** 안전하게 SANCTUM에 반영하는 독립 Windows 동반 프로그램을 만든다. 정식 명칭은 **Sanctum IRIS**, 프로젝트명은 **프로젝트_IRIS**다. `IRIS`의 영문 풀이는 아직 정하지 않았다.

IRIS는 기존 SANCTUM 웹을 대체하는 별도 서비스가 아니다. Windows 오버레이·로컬 연결기와 기존 웹/서버를 잇는 새 진입점이다. 한설은 장기적으로 엠포리온의 제작·경제 정보와 그노시스의 지식 기능까지 IRIS 안에서 융합하는 가능성을 제안했다. 이는 **탐색할 비전**이지 기존 메뉴·기능·데이터를 지금 통합하거나 폐지하라는 결정은 아니다.

## 3. 사용자 경험의 중심

1. 게임을 켠 상태에서 IRIS가 **연결됨/끊김/동기화 대기**를 분명히 보여 준다. 게임이 꺼졌거나 캐릭터 선택 화면이면 잘못된 값으로 덮어쓰지 않는다.
2. 크로노스: 일일·주간 남은 숙제를 작은 HUD에서 확인하고 체크한다. SANCTUM의 기존 숙제 ID·계정/캐릭터 범위·한국 시간 06시 초기화 규칙을 그대로 사용한다. 웹과 PC에서 어느 쪽을 눌러도 최종 상태와 저장 실패 여부가 분명해야 한다.
3. 본인 스탯: 게임에서 확인된 자기 캐릭터의 전투력·생활력 등을 **미리보기 → 승인/자동 동기화 설정** 순서로 반영한다. 캐릭터 소유자 매칭이 확인되지 않으면 저장하지 않는다.
4. 시낙시스: HUD에 현재 모집, 시간, 빈자리, 필요한 역할을 간단히 보여 준다. 처음에는 기존 `/party?join=ID`의 인증된 신청 흐름으로 연다. 신청·초대가 실제 저장됐는지 확인하고 중복 제출을 막기 전에는 오버레이의 직접 신청 버튼을 만들지 않는다.
5. 설정: 위젯별 표시/숨김, 위치, 크기, 투명도, 클릭 통과, 게임 종료 시 자동 숨김을 제공한다. 게임 조작을 가리는 UI가 되지 않도록 전체 숨기기 단축키와 안전한 기본 위치가 필요하다.

## 4. 권장 경계와 데이터 흐름

```text
공식 게임 커넥터 ──읽기 전용·본인 데이터──> Windows IRIS
                                            │ 로컬 HUD·사용자 확인
                                            ▼
                              인증된 SANCTUM 서버 API
                                            │ 소유권/기간/중복 검증
                                            ▼
                                크로노스·캐릭터 데이터

SANCTUM 시낙시스 ──인증된 모집 요약──> IRIS HUD
IRIS 신청 선택 ──기존 /party?join=ID──> 웹의 기존 신청 확인 흐름
```

- 게임 호출은 로컬 앱에서만 한다. 게임 데이터·로그인 코드·서비스 역할 키를 브라우저나 문서에 노출하지 않는다. `get_my_info` 성공은 **기술 가능성의 첫 신호**이지 모든 원하는 정보·이미지·게임 명령 사용 승인은 아니다.
- 서버에는 사용자의 SANCTUM 계정과 소유 캐릭터만 연결한다. 승인된 필드의 실제 변경분만 보내고, 같은 값·같은 요청의 중복 저장을 막는다. 로컬에서 빠르게 조회하더라도 DB 쓰기는 변경 시점에만 묶어 전송한다. 오프라인 재시도는 오래된 값이 새 값을 덮지 못하도록 기준 시각/버전을 검증한다.
- 길드원 최대 40명 베타에서 정기 전원 조회를 남발하지 않는다. 시낙시스 목록은 HUD가 열릴 때와 적절한 간격/변경 이벤트에만 갱신하고, 닫힌 상태에서는 멈춘다. 실제 간격과 Realtime 사용은 현재 API·RLS·부하를 먼저 측정해 결정한다.
- 프로필 초상화는 별도 조사 과제다. 공식·허용된 이미지 경로가 없다면 **본인 동의하에 직접 선택한 이미지**의 작은 썸네일을 저장하는 대안을 검토한다. 기본값은 수집 안 함이며 다른 플레이어 이미지·명단을 자동 수집하지 않는다.
- 제작 레시피·엠포리온 연동은 출처와 갱신권이 확인된 데이터부터 진행한다. 타 제작자의 1,834종 JSON을 허가 없이 흡수하지 않는다. 게임 내 자동 채집·제작은 읽기 전용 1차 버전과 분리하고, 정책·비용·정령의 날개·사용자 확인 절차가 검증되기 전에는 넣지 않는다.
