# IRIS 읽기 전용 HUD — 보관용 설계안

상태: 2026-10-11 검토안. 구현/CLI 계약/배포 승인 아님. 참조 ID: R02–R06, R17, L01–L04.

## 목표와 구조

애드온 바는 저장·파티·설정 조작을 맡고, HUD는 게임 위에서 선택한 정보를 관찰한다. 같은 관리 프로세스의 계정·보호 기록·게임 창 연동을 공유하며 구형 `overlay.ps1`과 새 앱을 동시에 실행하지 않는다. 기존 `DesktopOverlayCoordinator`의 addonMode 클릭 통과/투명도 제한은 그대로 둔다. HUD 전용 창 수명주기와 입력 정책을 별도로 연결한다.

후속 구현 단위는 데이터 계약 → 게임 미션 창 → 가공 창 → 시계/환경·무게 순이다. 한꺼번에 모든 창을 배포하지 않는다. 현재 현대 앱의 고정 읽기 명령은 스탯/재화뿐이며, 아래 항목을 이미 연결됐다고 표현하지 않는다.

## 데이터 계약과 흐름

- 공식 CLI의 허용된 고정 읽기 명령만 native에서 실행한다. 브라우저가 명령 문자열·실행 파일 경로·임의 인자를 전달하는 API는 만들지 않는다.
- 응답은 크기·깊이·문자열·수치 범위를 제한하고 타입으로 정규화한다. 각 snapshot은 `observedAt`, 출처, 지원 여부, 유효 데이터, 오류 상태를 구분한다.
- 미션 후보: 주기/목표/현재/남은 수량/완료/보상 수령. 실제 응답에 없는 구분은 `알 수 없음`이다. 생텀 숙제·임무게시판과 자동 매핑/자동 체크하지 않는다.
- 가공 후보: 시설/품목/등록·완료 개수/종료 시각 또는 잔여 시간. 총 생산시간이 없으면 시간 진행률을 만들지 않는다. 수령 버튼은 이 읽기 묶음에 없다.
- 환경 후보: 에린 시각/날씨/지역/채널. 서버 관측과 로컬 시간 추정을 표시로 구분한다. 환경을 게임 캐릭터 신원으로 쓰지 않는다.
- 무게 후보: 현재/최대/여유·과적. 소수 정밀도와 누락을 보존하고 알 수 없는 값은 0으로 만들지 않는다. R05 HP/포만감/버프는 지원 필드를 확인한 뒤 선택 추가한다.
- R17 퀘스트는 `조회 가능/빈 응답/미지원·실패`를 구분하는 확장 후보다. 빈 응답만으로 퀘스트가 없다고 단정하지 않는다.

## 조회와 표시

단일 조회 조정자가 스탯/재화와 HUD 요청을 직렬화·중복 합친다. 표시에 필요한 데이터만 조회한다. 초기 제안은 보이는 HUD 5초 간격, 사용자 설정 5~60초, 명령당 기존 8초 상한이다. 응답이 늦으면 다음 주기를 누적하지 않는다. 관측이 `max(2×주기,15초)`보다 오래되면 stale로 표시한다. 이 수치는 계약 시험 결과에 따라 착수 시 재검토한다.

숨김/게임 최소화·종료·연결 불가에서는 반복 조회를 멈춘다. 게임 종료 감지와 조회 실패는 구분한다. 재연결은 최신 snapshot을 읽을 뿐 완료 알림·생텀 쓰기·게임 작업을 자동 수행하지 않는다. 캐릭터 전환/새 세션에는 이전 snapshot을 새 캐릭터 정보로 표시하지 않는다.

## 창·입력·접근성

- 독립 소형 창을 사용자가 선택해서 켠다. 첫 실행은 HUD 꺼짐, 표시/알림은 명시 선택이다.
- 일반 모드에서 이동/접힘/설정이 가능하다. 클릭 통과는 HUD만 대상이며, 복구 단축키/트레이/관리창 경로가 유효할 때만 허용한다.
- 단축키 등록 실패·DPI 변경·모니터 분리에서 보이는 작업 영역 안으로 복구한다. 실종된 창을 투명도 0으로 숨기지 않는다.
- L02 위치 잠금/개별 배율·투명도/5초 숨김은 기본 HUD 복구가 검증된 뒤 도입한다. 설정에는 인증값·보호 큐 원문을 담지 않는다.
- 전역 6테마·큰 글자·긴 제목에 맞추며 설명/출처/마지막 조회를 읽을 수 있게 한다. 미션을 과하게 긴 목록으로 늘리기보다 접힘/페이지로 분리한다.
- L04 알림은 기본 꺼짐. 같은 관측 이벤트를 중복 알리지 않고 실패·빈 응답·stale을 완료 이벤트로 해석하지 않는다.

## 검증과 착수 조건

착수 때 공식 명령별 합성 응답/실측 필드 계약을 먼저 기록한다. 미지원·누락·0·소수·타임아웃·오래된 응답·전환 후 늦은 응답·조회 중 숨김을 테스트한다. 보이지 않는 창의 CLI 호출 0, 공유 요청 중복 없음, 단축키 실패 시 클릭 통과 거부, 복구 후 초점/경계 정상이어야 한다. 게임 조작·DB/RLS 변경 없이 합성/native 격리 시험 후 실제 표시·DPI 검증을 구분한다.

## 영향과 되돌리기

예상 변경 경계: `iris/desktop-bridge.cs`, 별도 읽기 normalizer/조회 조정자, `iris/desktop-overlay.cs` 주변 HUD 창 조정, typed snapshot·HUD UI·설정. 기존 보호 기록/업데이트 helper는 재사용하며 창 종료/업데이트 전 HUD 조회를 취소·정리한다. 오류 때 HUD를 끄면 기존 애드온 바만 계속 사용할 수 있어야 한다.
