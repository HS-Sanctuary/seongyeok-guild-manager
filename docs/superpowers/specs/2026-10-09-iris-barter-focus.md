# IRIS 물물교환·집중 UI — 승인 범위

한설의 2026-10-09 요청을 구현한다. CBT 배포는 보류하며 현재 폴더의 이전 미커밋 작업을 보존한다.

- 물물교환: 기존 `nexus_trades`와 본인 캐릭터의 `trade_checks` 값을 표시한다. 검색/범위·주기 구분, 횟수 버튼, 완료 표시를 컴팩트하게 제공한다. 게임 교환을 실행하지 않는다.
- 변경은 기존 보호 큐의 마지막 조작 15초 저장/지금 저장/계정·캐릭터 전환 보존을 따른다. 계정당 품목은 캐릭터 간 하나의 대기 변경으로 공유하며 실제 저장 사본 전체가 확인되어야 저장 완료다.
- DB 스키마·RLS·RPC·운영 수동 데이터 수정은 하지 않는다. 기존 JSONB를 소유권 확인 후 CAS로 변경하고, 다중 행 일부 성공/응답 누락은 보류 상태로 남긴다. 기존 버전 큐를 안전하게 읽고 보존한다.
- 클래스 전체 목록은 IRIS 창의 남은 세로 공간을 사용하고 목록 내부만 스크롤한다. 짧은 분류는 자연 높이를 유지한다.
- 캐릭터 추천은 창 중앙의 집중 대화상자로 표시한다. 바깥 클릭/Escape/아니요로 닫히고 자동 선택·스탯 저장·게임 입력은 없다. DOM 초점을 관리하되 OS 게임 초점을 빼앗지 않는다. 짧은 소리는 후보 표시마다 한 번, 소리 실패 시 시각 알림은 유지한다.
- 제목줄 톱니 왼쪽 사람 아이콘에서 중앙 계정 대화상자를 연다. 기억된 계정은 즉시 직접 선택하며 다른 계정 로그인/로그아웃을 제공한다. 계정 전환 전 미저장 데이터는 보관한다. 계정 메뉴와 설정/추천/종료 대화상자가 겹치지 않는다.
- 테마 대비, 12자 닉네임, 320px 폭/짧고 긴 창 높이, 키보드 조작을 확인한다. 원래 창 붙이기·같은 층·작업표시줄 우선 정책은 바꾸지 않는다.

완료 증거: 영향 범위 Node 테스트, 타입/대상 lint, 운영 연결 없는 합성 DOM 및 native 큐 검증. 실제 게임·실계정 저장은 자동 시험하지 않고 사용자 화면 확인으로 분리한다. 이번 요청에는 commit/push/배포가 포함되지 않는다.
