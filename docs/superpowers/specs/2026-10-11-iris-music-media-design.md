# IRIS 음악·미디어 — 보관용 설계안

상태: 2026-10-11 검토안. 참조 ID: R14–R16, L06, L09, A11–A12. 읽기/OS 조작/게임 행동은 별개 단계다.

## 단계와 화면

1. R14–R16 현재/주변 연주 상태와 악보·악기 목록을 읽기 표시한다. 익명·임시 식별자를 길드명부와 자동 대조하지 않는다. 곡 제목/남은 시간/합주 여부의 누락과 추정을 구분한다.
2. L06 Windows 미디어 리모컨: 실제 OS가 공개한 지원 세션만 사용자가 선택한다. 게임 커넥터와 다른 공급자이며 게임 연주 버튼으로 혼동하지 않는다. 브라우저/서비스 로그인·OAuth·유료 스트리밍 제공을 자동 포함하지 않는다.
3. A11 게임 연주/악기 변경/재생목록·반복은 생활 행동 안전 계약을 충족한 뒤 별도 승인한다.
4. A12 생활 작업과 연주 조정은 두 모듈의 단일 실행 소유권·양보/중지·복귀 의도 검증 뒤다. 실패한 작업/음악을 자동 재개하지 않는다.

## 데이터와 입력 경계

동명 악보는 확인된 원본 키로 구분한다. 초성/제목 정규화는 검색용이며 실행 키를 변형하지 않는다. 시작 직후 시간 0은 즉시 곡 종료로 판단하지 않는다. 익명 주변 연주를 본인 연주로 취급하지 않는다.

OS 미디어는 세션별 재생/정지/다음 등 지원된 조작만 노출한다. 연결 종료/세션 변경 후 낡은 대상을 조작하지 않는다. 실제 사용 가능 OS 버전·runtime·권한은 착수 때 공식 문서와 격리 시험으로 확인한다.

L09 곡 커버는 기본 테마 문양 또는 사용자가 선택한 권리 있는 이미지다. 파일 유형/크기/경로를 검사하고 외부 URL을 자동 내려받거나 공유하지 않는다. 주변 작곡자/악보 원문은 실제 지원 계약과 권리 전 표시하지 않는다.

## 검증과 되돌리기

누락/0/동명/합주 추정/세션 전환/여러 플레이어/권한 불가/OS 미지원에 대한 합성 시험을 만든다. OS API 또는 게임 연주 실제 실행은 지원·소유권 확인 후 해당 범위로만 시험한다. 플러그인을 끄면 조회/단축키/소유권을 해제하고 기존 애드온 기능은 계속 동작해야 한다. 운영 DB 변경 없이 분리 모듈로 제공한다.
