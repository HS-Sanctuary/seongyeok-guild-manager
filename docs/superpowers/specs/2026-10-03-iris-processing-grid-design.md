# IRIS 가공 읽기 위젯

승인된 가공3×2 요청을 첫 읽기 전용 단계로 구현한다. 금속/목재/가죽/옷감/약품/식재료 순서의 6칸, 항목명·완료/등록 수·가장 이른 양수 남은 시간, 완료 비율 게이지다. 전체 생산시간/경과 시간 응답이 없으므로 생산 시간 퍼센트를 추정하지 않는다. 조회 실패는 대기/0개가 아니라 조회 불가, 연결 해제는 모든 칸을 비운다. 빈 정상 목록은 대기다.

기존 snapshot에 시설별 total/remainingSeconds만 추가한다. DisplayName 원본/개인 식별정보는 보내지 않는다. facility category는 공백 제거 후 정확히 `<종류>가공시설` 또는 `<종류>가공`만 식별한다. 미확인 시설 이름을 다른 종류로 임의 대입하지 않는다.

이 단계에는 수령 실행 버튼이 없다. 수령은 다음 별도 명시 실행/중지/인증 경계를 갖춘 기능이다. 스테이터스와 미션 표시, 센터·설정·단축키는 그대로 유지한다.
