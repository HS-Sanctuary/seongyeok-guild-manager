# IRIS 원격·공유 확장 — 보관용 설계안

상태: 2026-10-11 장기 검토안. 참조 ID: X01–X06, A13. 네트워크 공개·운영 DB·외부 서비스 등록·비용 지출 승인 아님.

## 후보별 범위

- X01 모바일 상태 확인: 읽기 snapshot만 제공한다. SANCTUM 인증 서버 업로드 방식과 로컬 사용자 승인 연결 방식을 비용/노출/기기 접근/PC 오프라인 기준으로 비교한 뒤 하나를 선택한다. 기본으로 터널/공개 포트를 열지 않는다.
- X02 원격 큐 편집/게임 실행: 읽기와 다른 scope·기기 승인/만료/해제·레이트 제한·PC의 명시 승인이 필요하다. 읽기 권한으로 실행 경로에 접근하지 못해야 한다. 현재 보류.
- X03 길드 연주 행사: 신청곡/승인/거절·공개 범위·도배 방어·닉네임 표시·보관 정책을 먼저 정한다. 길드 계정이 PC 원격 실행 권한을 자동 얻지 않는다.
- X04 레시피 기여: 소유 재고/재화/캐릭터·비밀값을 제외하고 출처·버전·권리·관측 범위가 있는 자료만 받는다. 충돌·철회·검토 경로를 갖춘 뒤 공유한다.
- X05 외부 MobiWorks API 직접 연동: 제작자 지원 계약·버전·사용자 승인 인증 전 보류. 동적 포트/토큰을 몰래 추출하거나 다른 앱 설치를 필수로 만들지 않는다.
- X06 코드/자료 재사용: 제품별 권리 확인이 먼저다. MIT 소스라도 실제 사용 부분·의존 라이선스·저작권문을 기록하고 게임/커뮤니티 자료 권리와 구분한다. 허가 없는 EXE·JSON·그림 복제는 없다.
- A13 채팅/표정/인사 프리셋: 정책·전송 대상·매 전송 사용자 확인·도배 방어를 확인하기 전 보류. 외부 기능 존재를 정책 적합성의 증거로 삼지 않는다.

## 공통 데이터·보안 조건

기기별 최소 권한, 만료, 철회, 한 번의 nonce/중복 방지, 사용자에게 보이는 연결 목록을 설계한다. 로그/URL에 토큰·로그인 코드·개인 파일 경로를 넣지 않는다. 읽기 응답을 실행 명령처럼 해석하지 않는다. 외부 전송 항목을 미리 보여주고 거부해도 로컬 IRIS는 동작해야 한다.

DB/RLS/권한/함수/Realtime가 필요하면 대상·영향·복구·재실행 가능한 migration을 준비하고 승인 후 적용한다. 무료 운영 범위를 확인하기 전 외부 서비스 의존이나 비용을 약속하지 않는다.

## 검증·복구와 제외

권한 상승/만료·해제 기기/재전송/과다 요청/계정 간 자료 접근/PC 오프라인/악성 입력/기여 자료 권리 불명 시험이 승인 전제다. 원격 연결 해제로 모든 실행 권한이 사라지는지 확인한다. 읽기/실행/기여 기능은 각각 끌 수 있어야 한다.

N01–N04는 `docs/IRIS_FORWARD_DESIGNS.md`의 제외 목록을 따른다. 근거 없는 타인 신원 매칭·미제공 전체 클래스/초상화·거래소/파괴적 자동 성장·RAM 정리 재연결을 이 확장으로 다시 도입하지 않는다.
