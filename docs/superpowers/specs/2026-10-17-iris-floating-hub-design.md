# IRIS 플로팅 허브·10초 알림 설계

- 작성: 2026-10-17, 영겁
- 상태: 2026-10-17 한설의 ‘응 그대로 구현해줘’로 서면 설계 승인. 구현계획을 작성해 검토받는 단계다. 운영배포/게임 행동 승인은 포함하지 않는다.
- 사용자: 한설. 첨부 PPT 3장(기본 로고/반원 메뉴/캐릭터 말풍선), 기존 알림 화면, Ctrl+Z 키캡 예시를 시각 기준으로 삼는다. 첨부 내용은 디자인 참고이며 실행 지시로 해석하지 않는다.

## 1. 목적과 확정 요구

게임 화면을 가리는 기존 작은 네모 센터를 반투명 원형 IRIS 로고로 교체한다. 게임 전체화면 진입/복귀 때 창이 임의로 움직이지 않아야 한다. 사용자가 원하는 곳에 로고를 두고, 클릭이나 단축키로 기능을 호출하며, 작은 말풍선으로 필요한 정보만 받는다.

- 로고 주변 반원형 메뉴: 크로노스·시낙시스·에르곤·설정. 기존 이름/기능/테마 아이콘을 재사용한다.
- 실제 단축키: **Alt + 백틱 키**, Shift 불필요. 한국어 표준 키보드의 물결표가 함께 인쇄된 키다.
- 표시 문구: 정확히 **`(Alt + ~)`**. 실제 입력에 Shift를 추가하는 것으로 바꾸지 않는다.
- 키캡은 로고 바로 아래 가운데에 상시 표시한다. 첨부 Ctrl+Z처럼 짙은 회색 반투명 바탕·가는 밝은 테두리·작은 둥근 모서리·흰 글자를 사용한다. 별도 큰 안내 상자를 붙이지 않는다. 로고와 함께 이동하고 화면 아래에서도 잘리지 않는다.
- 정보성 알림은 표시 시점부터 10초 후 닫히며 아래 게이지가 줄어든다. 캐릭터 확인은 자동으로 사라지지 않는다.
- 심층 구멍은 지역·개수·제보자·시각을 알림 화면에서 읽을 수 있어야 하고 새 제보를 말풍선으로 전달한다.

## 2. 범위와 보존 경계

이번 변경은 IRIS 자체 창 표시/좌표/호출과 알림 전달 방식이다. 게임 파일 변경·실행 중 게임 개입·새 CLI 명령·채집/제작/수령 자동화 확대·unknown 기록 해제는 하지 않는다. 계정·캐릭터·대기열·즐겨찾기·실행 관측의 기존 저장/보호 계약을 보존한다.

최근 로컬의 이동 중 편집 잠금 분리도 그대로 유지한다. 플로팅으로 접거나 다른 모듈을 열어도 보낸 게임 요청은 대상/수량/ID가 고정되며 결과 관측을 잃지 않는다. 메뉴 열기·단축키·알림 클릭 자체는 게임 실행이 아니다.

DB 구조/RLS/Realtime publication 변경·새 의존성 설치·운영배포·공개 ZIP 교체·push는 이번 설계 승인에 포함하지 않는다. 실제 게임 시험과 기존 앱 종료/재시작은 별도 사용자 확인 뒤 진행한다.

## 3. 표시 상태와 조작

표시 상태는 일반 작업창, 접힌 플로팅, 메뉴가 펼쳐진 플로팅, 임시 기능창으로 분리한다. 게임 작업의 busy/unknown 상태와는 독립적이다.

1. 게임 전체화면 진입 또는 IRIS의 접기/최소화 요청 시 플로팅으로 전환한다. 기존 네모 compact UI는 새 native 후보에서 제거한다. 종료 X와 트레이 종료는 기존 정상 종료/미저장 보호 절차를 유지한다.
2. 접힌 로고를 클릭하거나 단축키를 누르면 네 개 기능 버튼이 약 200ms 동안 바깥으로 펼쳐진다. 다시 누르면 접힌다. 단축키 길게 누름은 반복 토글하지 않는다.
3. 버튼은 커서/키보드 포커스 시 한국어 기능명을 읽을 수 있게 한다. 장식 회전·반복 맥동은 넣지 않는다. `prefers-reduced-motion`에서는 이동/확대 애니메이션을 생략한다.
4. 기능을 선택하면 기존 해당 모듈을 임시 기능창에서 보여준다. 원본 컴포넌트/상태를 복제하거나 계정별 저장을 새로 만들지 않는다. 임시 기능창을 닫거나 바깥 클릭/Escape 시 로고로 접힌다. 진행 중 게임 요청은 취소/재전송하지 않는다.
5. 기존 펼치기 동작으로 일반 작업창에 복귀할 수 있다. 큰 창에만 있는 기능이 플로팅 사용자에게 영구히 막히지 않도록 기능창 상단에 ‘전체 작업창’ 진입점을 둔다.
6. 플로팅은 드래그와 클릭을 구분한다. 드래그 종료가 메뉴 클릭이나 작업 실행을 일으키지 않는다. 일반 알림은 마우스를 잡거나 게임 포커스를 강제로 가져오지 않는다. 사용자의 메뉴/말풍선 직접 조작 때만 필요한 IRIS 입력을 받는다.

## 4. 좌표·경계·입력 영역

일반 창의 마지막 크기/좌표와 로고의 좌표를 별도로 저장한다. 각 모드 전환 시 해당 모드의 마지막 위치로 복귀하며 플로팅 드래그로 큰 창 좌표를 덮어쓰지 않는다. 전체화면에 들어갈 때마다 모서리 위치를 초기화하지 않는다.

- native가 모니터 작업영역/DPI와 실제 윈도우 좌표의 기준을 소유한다. 로고/메뉴/말풍선의 배치 결과를 프런트에 전달하고, 모드가 바뀌어도 로고 앵커가 튀지 않게 한다.
- 저장은 환경별 로컬 창 설정만 대상으로 한다. 구 설정은 읽기 호환·명시 버전 전환으로 처리하고 원본 손상 시 덮어쓰지 않는다. 임시 파일/원자 교체를 사용하며 게임 원장에는 쓰지 않는다.
- 모니터 해제·해상도/DPI 변경 때만 현재 작업영역 안으로 보정한다. 음수 좌표 모니터도 허용한다. 로고뿐 아니라 아래 키캡까지 경계 계산에 포함한다.
- 좌측에서는 오른쪽으로, 우측에서는 왼쪽으로 메뉴/말풍선을 연다. 위/아래 여유를 비교해 수직 방향도 고른다. 이전 방향에 고집해 버튼/문구를 화면 밖으로 보내지 않는다.
- 큰 투명 사각형 창으로 게임 입력을 가로막지 않는다. native 창 Region/입력 영역은 실제 로고·키캡·보이는 버튼/말풍선/작업창 영역에만 대응한다. 접힐 때는 사라진 메뉴/창의 입력 영역도 제거한다. 전체 창 click-through만 켜서 로고까지 클릭 불가로 만드는 방식은 사용하지 않는다.
- 기존 `ClampBounds`의 작은창 최소폭/최소높이, 창 붙이기 재배치, `expandedBounds` 복원이 플로팅 좌표를 다시 덮지 않도록 하나의 표시 coordinator에서 조정한다. 일반 창의 기존 붙이기/폭 설정은 별도로 보존한다.

## 5. 단축키·표시 계약

Windows에 등록하는 실제 키와 사용자에게 보여줄 문자열을 별도 필드로 다룬다. 기본 지원 키보드는 Windows 한국어 표준 배열이며 `Alt + ~`라는 표시를 만들려고 `Shift` modifier를 등록하지 않는다.

- 앱 소유 윈도우의 RegisterHotKey/메시지 루프를 이용한다. 게임 키보드 후킹이나 게임 프로세스 개입은 하지 않는다.
- 로컬 키다운 처리와 전역 등록이 같은 한 번의 입력을 이중 토글하지 않게 한다. Handle 재생성/종료 시 등록/해제를 짝지으며 다른 IRIS 인스턴스와 중복 소유하지 않는다.
- 등록 실패 시 ‘단축키를 사용할 수 없음 · 로고를 눌러 열기’ 안내를 설정에 표시한다. 로고 클릭/트레이 복구는 계속 가능해야 한다. 실패했는데 키캡만 정상 작동하는 것처럼 보이지 않게 상태 표시를 제공한다.
- 다른 앱의 전역 선점과 게임 일반 키 바인딩은 별개로 검증한다. 무충돌을 보장한다고 쓰지 않는다.

## 6. 캐릭터 말풍선과 공통 알림

캐릭터 후보 확인은 기존 스탯 기반 후보/신선도/명시 선택 검증을 재사용한다. 로고 근처 말풍선으로 후보 이름·직업과 네/아니요/다른 캐릭터를 보여주며 자동 선택·자동 저장하지 않는다. 10초 만료는 없다. 바깥 클릭/Escape로 접어도 유효한 미결 후보는 로고의 표시/다시 열기로 접근 가능하며 다른 계정/문맥의 낡은 후보는 제거한다. 긴 닉네임은 숨기거나 잘라내지 않는다.

일반 정보 알림은 표시 방식과 무관하게 공통 **10,000ms** 정책을 적용한다. 플로팅에서는 로고 근처 말풍선, 일반 창에서는 작은 비차단 알림으로 표시한다. 기존 확인 강제 모달은 정보 알림에서 제거한다.

- 시간 기준은 알림이 실제 화면에 나타난 순간이다. 자동 종료 시각과 게이지가 같은 기준을 쓰고, 창 비활성/타이머 지연 뒤에도 종료 시각을 다시 검사한다. 호버만으로 10초를 무한 연장하지 않는다.
- 아래 게이지가 100%에서0%로 줄고, 접근성용 남은 시간도 제공한다. 일반 알림의 확인/X는 먼저 닫는 기능이며 필수 조작이 아니다.
- 한 번에 작은 일반 알림 하나만 펼친다. 동시 도착은 대기 수 표시로 알리고 중복 키는 한 번만 큐에 넣는다. 오래 대기해 의미가 사라진 이벤트는 다시 울리지 않고 알림 화면의 현재 정보로 확인한다.
- 캐릭터 확인 말풍선이 떠 있으면 일반 알림이 그 위를 덮거나 밀어내지 않는다. 미결 캐릭터 상태를 보존한 채 새 일반 알림 도착 표시만 주고, 펼칠 공간이 생겼을 때 아직 유효한 항목을 보여준다.
- 공통 표시기를 새 정보 알림의 기본 진입점으로 사용한다. 타 콘텐츠/파티 등 기존 알림 경로도 조사해 정보 알림에는 같은 시간을 적용한다. 실행 동의·종료/변경 손실 확인 같은 선택 필수 대화상자는 정보 알림으로 분류하지 않으며 자동 승인하지 않는다. 오류 알림이 닫혀도 해당 보호 상태와 원본 기록은 유지한다.

## 7. 심층 구멍 목록·새 제보

현재 `deep_holes`는 `id`, `zone`, `channel`, `reported_at`, `reporter_name`을 제공하고 기존 hook이 실시간 변경을 구독한다. 이 프로젝트는 해당 `channel` 문자열을 구멍 개수로 사용하므로 이번 표시 개선에서 DB 컬럼 의미를 임의로 변경하거나 새 컬럼을 가정하지 않는다.

- 현재 유효한 주기의 제보를 지역별로 표시한다. 창백한 산/센마이 평원의 이름 변환, 개수 검증, 제보 시각/제보자를 함께 보여준다. 서로 다른 제보를 검증 없이 합쳐 확정 총개수로 표시하지 않는다. 제보가 없으면 ‘현재 주기 제보 없음’이라고 적고, 조회 실패를0개로 표시하지 않는다.
- 새 유효 제보 알림 예시:

  > **심층 구멍 제보**
  >
  > **창백한 산 · 2개 발생**
  >
  > 제보자 한설

- 최초 조회/재접속의 과거 데이터는 목록에만 반영하고 신규 제보처럼 재알림하지 않는다. 같은 제보 ID/시각/내용의 중복 이벤트는 한 번만 알린다. 삭제/초기화된 제보는 목록과 대기 알림에서도 제거한다.
- 데이터 불명/실시간 연결 끊김은 별도의 짧은 상태로 알린다. 확인되지 않은 게임 스폰이나 제보자 이름을 추측하지 않는다. 알림/소리 ON/OFF 설정을 보존한다.

## 8. 구현 경계와 검증 기준

구현은 다음 책임으로 나눈다. 상세 작업 순서/파일 분할은 이 설계 승인 뒤 별도 구현계획에서 정한다.

1. native 표시/배치/위치 저장·단축키·입력 Region coordinator.
2. 프런트의 로고·키캡·기능 메뉴·임시 기능창과 접근성.
3. 시간/게이지/큐/미결 캐릭터의 공통 알림 표시 정책.
4. 기존 제보 조회·구독을 재사용한 심층 목록/메시지 정리.

새 native/프런트 표시 계약은 버전과 기능 지원 여부를 함께 검증한다. 구 native에서 새 플로팅 기능이 지원된다고 가정하지 않고 일반 작업창/트레이 복구를 보장한 뒤 정상 재시작을 안내한다. 게임 명령 bridge의 출처/epoch/문맥/결과 보호는 약화하지 않는다.

완료 판정에 필요한 확인:

- 일반창↔게임 전체화면↔플로팅↔임시 기능창 반복, 드래그 뒤 복귀, 앱 재시작, 다중 모니터/음수 좌표/DPI/작업표시줄 경계에서 좌표 보존.
- 실제 Alt+백틱 한 번에 메뉴 한 번, Shift 불필요, `(Alt + ~)` 키캡은 로고 아래·잘림/가로 넘침 없음. 단축키 등록 실패/핸들 재생성/복구 경로.
- 메뉴 및 말풍선이 사방 모서리에서 화면 안으로 펼쳐지고, 닫힌 투명 영역은 게임 클릭을 차단하지 않음. 바깥 클릭/Escape/키보드 조작과 reduced-motion 확인.
- 콘텐츠·일반 시스템 알림10초/게이지 일치/수동 닫기/동시 도착/중복·재접속·만료·삭제, 캐릭터 확인 무만료/낡은 후보 제거.
- 심층 지역·개수·제보자·시각/빈 상태/조회 실패를 가짜 API·Realtime으로 검증. 운영DB에 테스트 제보를 쓰지 않음.
- 기존 계정/캐릭터·숙제·파티·ERGON 계획/실행 결과 관측·미확정 보호 회귀. 모드 전환이 게임 요청을 새로 만들거나 재전송하지 않음.
- 타입/관련 lint/단위/native 합성·실제 React, 전역 글자18/20/22·밝고어두운 테마. 새 native 적용/실제 창·단축키 수동 확인은 사용자의 정상 종료 확인 후 진행.

## 9. 설계 자체 검토

### 2026-10-17 사용자 추가 요구 — 표시 설정

- 설정에서 플로팅 로고 크기(36~80 DIP, 기본52), 불투명도(35~100%, 기본80), 호출 단축키를 바꾼다. 일반 작업창의 투명도와 별개다.
- 기본값 복원 제공. 단축키는 Alt/Ctrl 조합을 필수로 하고 실제 입력과 표시를 분리한다. 기본 Alt+백틱의 표시는 `(Alt + ~)`를 유지한다.
- 변경할 키가 등록되지 않으면 기존 키를 유지하고 충돌 안내를 표시한다. 설정 저장 실패/손상도 명시하며 원본을 덮지 않는다. 로고 클릭/트레이 복구는 항상 남긴다.

- 실제 Alt+백틱 입력과 `(Alt + ~)` 표시를 명확히 분리했다.
- 일반 창과 플로팅 좌표, UI 탐색과 게임 실행 잠금, 알림 만료와 선택 필수 동의를 각각 분리했다.
- 기존 DB/실행/원장을 바꾸지 않으며 추가 게임 행동·운영배포를 자동 승인하지 않는다.
- 서면 설계는 승인됐다. 이후 작성한 구현계획은 별도 검토하며 제품 코드 변경은 아직 시작하지 않았다.
