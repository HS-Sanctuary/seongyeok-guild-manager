# IRIS 상점구매·임무게시판 설계

한설은 2026-10-10 KST 잠든 동안 추가 질문 없이 안전한 로컬 구현을 위임했다. 현재 권한을 유지하며 긴 글자·버튼·카드 넘침 방어를 포함한다. 운영 DB 구조/권한 변경, push/배포/공개 게시, 실게임 조작과 시험용 운영 쓰기는 제외한다.

## 목적과 범위

- IRIS 크로노스의 상점구매·임무게시판을 활성화한다. 실제 구매/임무 수행이 아니라 생텀 기록 직접 수정이다.
- 기존 kronos_shop_items/kronos_missions/kronos_progress를 서버 인증 후 재사용한다. 본인 캐릭터만 쓰며 계정당 구매는 같은 계정의 공통 진행이다.
- 검색, 즐겨찾기 우선/필터, 미완료 필터, 일간/주간 구분, ±/MAX/MIN을 제공한다.
- 횟수와 즐겨찾기는 마지막 수정 15초/지금 저장, 기존 DPAPI 보호 대기함·계정 전환 보관·재시작 후 확인·모호한 결과 중단을 따른다.
- count와 bookmark는 독립된 편집 차원이다. 서버는 원하는 절대값 CAS를 수행하고 기존 다른 차원/다른 캐릭터 기록을 보존한다. 반복 delta RPC 재전송은 사용하지 않는다.
- 현재 기간/카탈로그/계정/소유권 검증, 중복·범위·응답 유효성 검사. 기간 경계 뒤 자동 이전 의도 적용 금지.
- 기존 schema3 대기함에 workspace kind를 추가하되 새 native 지원 확인 전 편집 금지. 과거 대기함은 보존한다.
- 320/390/768/1280 폭과 18/20/22 글자에서 긴 닉네임/문구/9999 수치가 읽히며 버튼은 짧게, 조작줄은 필요하면 별도 행으로 재배치한다.

## 후속

시낙시스 일반 파티·길드버스 생성은 본 묶음 완료 후 사용량에 따라 별도 설계/구현한다. 운영 생성 테스트는 하지 않는다. 추가 SQL이 필요하면 목적/영향/복구와 아침의 필요한 행동을 기록한다.
