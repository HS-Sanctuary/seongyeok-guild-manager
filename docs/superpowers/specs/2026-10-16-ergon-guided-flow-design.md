# ERGON 현황과 연속 작업 동선

2026-10-16 순월. 한설은 직전 브리핑의 후속 구현을 승인했고 이번 5시간 잔여15% 중단을 철회했다. 기존 즉시 설계 갱신·직접 구현 선호를 적용한다.

## 사용자 결과

생활현황은 날개/가방/완료 3칸을 한 줄로 읽고 짧은 새로고침을 사용한다. 일반 조회는 보이는 대기 화면에서15초마다 한 묶음씩 실행한다. 준비/실행/숨김에는 중단하고 돌아오거나 작업이 끝나면 즉시 갱신한다. 실행 결과 관측2초와 native15초 신선도는 변경하지 않는다.

제작 목표와 필요한 선행 작업을 분리한다. 예를 들어 제작3개→상급목재 부족6개→통나무 부족분을 계산하여 바로 준비할 수 있다. 선행 작업은 저장된 최종 목표를 늘리거나 덮어쓰지 않는다. 완료 뒤 실제 재고로 다음 단계를 다시 계산한다. 원래 목표로 돌아가는 버튼을 제공한다.

## 계산과 실행 경계

- 참고 재료표는 계속 complete:false다. 계산된 경로가 실제 게임의 완전한 BOM이라는 보장은 없다. 실행은 기존 native 재조회/동의/수량한도/보호기록을 사용한다.
- 동일 가공품의 등록 작업이 있으면 추가 등록 권유 전에 대기/수령을 우선한다. 등록수는 시설정원이 아니며, 예상 생산량을 가방 재고로 더하지 않는다. 완료품은 기존 시설 전체수령 버튼으로 연결한다.
- 루트 추가 목표/확인된 제작진척은 기존처럼 유지한다. 임시 선행 작업은 환경·계정·캐릭터·루트목표에 묶는다. 변경/삭제/범위이탈 시 폐기하며 자동 재전송하지 않는다.
- 자동 계산·동선 연결과 무인 소비를 구분한다. 이번 동선은 직접 준비/기존 native 동의다. 완전BOM·정원·수령비용이 확인되기 전 무인 총예산 생산은 활성화하지 않는다.
- 기존 개인 파일, 공개버전, DB, 보호 원본, 운영배포는 그대로다. 실제 게임 소비 시험은 수행하지 않는다.

## 검증

실제React/가짜native IO로15초·숨김·실행·늦은응답·완료후갱신·계정전환,3칸/320~1240px·18/20/22글자, 루트보존/부족분→선행준비→완료후재계산/가공대기·수령/unknown 차단을 확인한다. 순수 계산은 stale/중복경로/불명등록/한도/중복 클릭을 확인한다. 전체Node·타입·관련lint·빌드 및 단일 최종리뷰로 마감한다.
