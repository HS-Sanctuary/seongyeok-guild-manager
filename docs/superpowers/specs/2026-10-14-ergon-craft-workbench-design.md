# ERGON 수량 제작·통합 작업대

한설 요청: 추가 생산 수량대로 제작하고, 필요한/보유/부족 재료·날개·시설을 한 화면에서 확인한다. 부족 재료 채집→가공→제작의 연계를 향해 작업한다. 2026-10-14 이번 작업은 잔여15% 중단 및 push 지시가 철회됐으며 로컬에서 이어간다.

후속 지시(퇴근 전):15%잔여에서검증/인계/기능브랜치push를다시승인했다. 위철회는당시경과. 운영main/공지/공개ZIP배포는포함하지않으며새게임소비/unknown해제를이요청으로추정하지않는다.

## 확인 근거와 경계

- 공식 execute_crafting은 craftCount를 지원하며 명령당 날개5, 완료 응답에 craftCount가 있다. 현재 IRIS는 1 고정이다.
- 공식 get_items는 재료/소비품만 지원하고 장비를 제외한다. 빈 조회를 장비0으로 판단하거나 제작 성공을 재료 재고 증가만으로 판정하지 않는다.
- 신규 수량 제작은 최대5 제작 횟수/명령1회/날개5로 시작한다. 목표는 이번에 추가할 결과물 수량이며 ceil(목표/1회 산출량)을 준비한다. 산출단위 초과분과 시설 한도 거절을 표시한다. 자동 재시도/추가 소비명령은 없다.
- native 확인은 품목·제작 횟수·예상 결과·계정/캐릭터·날개를 고정한다. 공식 완료 응답 횟수와 정확한 날개 차감을 대조한다. 조회 가능한 결과의 재고가 줄거나 늘지 않으면 미확정이다. 조회 불가 장비는 null을 유지하고 공식 결과로 확인한다.
- 과거 unknown 기록은 자동 해제/삭제하지 않는다. 손상 기록·통신 불명 결과는 기존 보호를 유지한다.
- 목록/선택/수량/재료/시설/실행을 작업 계획 화면에 모아 탭 왕복을 줄인다. 기존 실행 컴포넌트의 실행 상태와 보호 기록을 계속 유지한다.
- 전체 재료표가 없으면 MissingIngredients(현재1회 부족분)만으로 완전 BOM을 추측하지 않는다. 완전성 미확인 재료표는 연쇄 자동 실행에 사용하지 않는다. 창고는 가방 보유로 합치지 않는다.
- 한설이 생활 커넥터 내부 자료 참고를 요청했고 사무실 설치 경로에서 두 고정 JSON이 확인됐다. optional read-only adapter는 선택 품목의 재료 사실만 읽는다. 파일 자체/코드/데이터 번들을 제품이나 Git에 복사하지 않으며 cached Owned/Craftable을 현재 캐릭터 값으로 사용하지 않는다. 날짜/installed-reference/complete=false를 표시하고 공식 산출·재료 수량과 충돌하면 참고 계산을 제외한다. 임의 경로/스크립트 실행·설정/즐겨찾기·로그 읽기 금지.
- DB/운영/public ZIP/공지 변경 및 push 없음. 실게임 소비 시험은 사용자 native 확인으로만 한다.

## 후속: 부족분 수급 순서 미리보기

- 한설이 사진처럼유기적인한눈동선을요청했다. 선택목표→현재가방차감→필요가공의선행재료→채집/수동확보→가공수령→제작 순서를읽기전용으로표시한다.
- fresh 가방만예약해공유재료를중복차감하지않고, 가공산출단위초과분은가상남은재고로한계획안에서재사용한다. root목표는추가결과물이라기존최종품재고를목표에서차감하지않는다.
- 같은이름에여러공급경로/잠김·동명다른분류·미확인수량/참고충돌/미확인재료표/순환/32node·8depth한도는명확히차단상태로표시한다. 창고를가방으로합치거나괄호레시피명을출력명으로자동추정하지않는다.
- 현재gamecatalog와selected installed-reference만사용, 필요부족품의reference만중복합쳐최대32건조회. 파일번들은복사하지않는다. 종류·품목변경/숨김/잠금시지연조회폐기, 자동게임명령0.
- root제작은5회묶음기준최소날개/1회씩최대날개, 가공등록5/회, 채집최대100묶음기준최소날개를표시하되수령비용·초과채집/시설제한미확인은총상한미확인으로알린다. 이수치를실행가능예산으로승격하지않는다.
- 각확인가능단계는계획추가만가능하다. 자동전체chain과검증전채집품실행은비활성, 기존unknown과native최종확인유지. 실게임최종검증및fullBOM권한/신뢰문제는남은작업에포함한다.
