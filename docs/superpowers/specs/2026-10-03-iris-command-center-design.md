# IRIS Command Center · first settings slice

한설의 2026-10-03 요청에 따른 로컬 구현. 기존 미커밋 모듈 작업을 이어 사용한다. 추가 승인 대기는 생략하도록 명시적으로 지시받았다. 운영 DB·배포·Git 커밋은 별도 승인 범위다.

- 커맨드센터와 개별 위젯 ×/사용자 창 닫기는 숨기기다. 개별 위젯은 기존 표시 버튼으로 복구한다. 센터는 트레이 또는 Ctrl+Alt+I 한 번으로 복구한다.
- 전체 종료는 센터/트레이의 별도 종료 버튼에서 Yes/No 확인 후 실행한다. 기본 선택은 No, 중복 확인 방어를 둔다. OS 종료는 막지 않는다.
- 첫 설정 묶음: 생텀 6대 테마와 전체 창 불투명도 40~100%. 투명도 0으로 복구 수단을 잃지 않도록 제한한다. 창 전체에 적용되므로 글자도 함께 투명해지는 alpha 제한을 안내한다.
- 설정은 표시 설정만 별도 파일에 저장한다. 계정·게임 수치·인증값을 저장하지 않는다. 손상/범위 밖 값은 기본값으로 복구한다.
- 이번 묶음에는 자동 종료/저장 체크보드/실제 가공 수령/방송 연출/미디어 원격 제어가 포함되지 않는다. 기능은 각각 후속 독립 묶음으로 구현한다. 자동 종료 설정은 저장 실패·미저장 체크 보존까지 갖춘 뒤 추가한다.
- MoFo는 기능 구분 참고일 뿐 레이아웃·그림·연출 코드는 복제하지 않는다. AI아님 커넥트의 정확한 기능 목록은 미확인이다.
