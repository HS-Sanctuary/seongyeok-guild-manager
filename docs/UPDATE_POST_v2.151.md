# SANCTUM BETA v2.151 업데이트 안내

작성자: SANCTUM 시스템 · 분류: 생텀 업데이트
게시 상태: 초안 — 서비스에 게시하지 않음

성역 여러분, 알려 주신 크로노스의 불편함 두 가지를 수정했습니다. 🌿

검은 구멍의 최대 횟수가 월요일 자정에 먼저 줄어들던 문제를 고쳤습니다. 게임의 하루는 한국 시간 새벽 06시에 바뀌며, 주간 초기화는 월요일 06시입니다. 검은 구멍은 월요일 8회, 화요일 9회, 수요일 10회, 목요일 11회, 금요일 12회, 토요일 13회, 일요일 14회로 표시됩니다. 일요일의 14회는 다음 월요일 06시 전까지 유지됩니다.

물물교환·상점 구매·임무 게시판에서 더보기 문양 뒤가 검게 보이던 부분도 각 테마 배경에 어울리게 다듬었습니다.

열어 두셨던 화면은 한 번 새로고침해 주세요. 기존에 저장된 완료 기록을 삭제하거나 자동 복구하는 업데이트는 아닙니다. 새벽 06시를 지나 계속 열어 둔 화면도 새로고침해 확인해 주세요.

꼼꼼하게 알려 주셔서 감사합니다. 사용 중 표시가 맞지 않는다면 어느 화면에서 어떤 일이 생겼는지 운영진에게 알려 주세요. ✨
