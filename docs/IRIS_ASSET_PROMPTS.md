# IRIS 작은 SVG 마크 요청 예시

아래 문장에서 문양 설명만 바꿔 요청한다.

> 첨부 이미지의 **가마와 아래 불꽃 문양만** 참고해 작은 UI 아이콘용 SVG로 만들어줘. 배경·사진·글자·그림자 없이 하나의 단색 실루엣으로 정리해줘. 실제 벡터 path로 작성하고 PNG/JPEG를 SVG에 삽입하지 마. 정사각형 viewBox="0 0 64 64", 사방 약 4단위 여백, fill="currentColor"를 사용해줘. 고정 흰색/검정색 없이 밝고 어두운 테마의 글자색을 그대로 따라야 해. 16~24px에서 가마와 불꽃이 구분되도록 세부 묘사는 단순하게 하고, 외부 링크·폰트·필터·스크립트 없이 완성된 .svg 파일을 줘.

## 적용

- 폴더: `public/svgs/UI mark/`. 생활 마크의 URL은 `/svgs/UI mark/생활 마크.svg`다.
- 단색 문양은 CSS mask + `background:currentColor` 또는 inline SVG로 사용한다. `<img>`는 상위 요소의 currentColor를 그대로 전달하지 않는다.
- 크기는 글자와 함께 변하는 `em`/`rem`을 기본으로 하며 좁은 메뉴에서는 글자가 잘리지 않도록 컨테이너 폭도 고려한다.
- 생성 후 작은 크기, 밝은 테마, 어두운 테마에서 실제로 확인한다. SVG 확장자만 붙인 비트맵은 벡터 아이콘이 아니다.
