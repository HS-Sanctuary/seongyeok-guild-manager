# IRIS 후속 설계 색인

2026-10-11 / 영겁. 한설 요청: 미래 요청을 잊지 않도록 설계안으로 보관하고, 현재 한 묶음씩 진행한다.

## 현재 작업과 완료 기준

현재 **애드온 바 탐색 정리**는 승인 계획에 따라 로컬 구현·합성 검증을 마쳤다. 기존 기능/미저장 기록 유지, 7개 기능 접근, 패널 닫힘/키보드, 테마·반응형, 관련 테스트·타입·빌드 통과를 확인했다. 실제 사용자 앱 시험·새 버전·push는 이번 요청에 포함되지 않는다.

- 승인 설계: `superpowers/specs/2026-10-11-iris-navigation-design.md`
- 승인 계획: `superpowers/plans/2026-10-11-iris-navigation.md`
- 기준 완료 제품: Beta 0.2.2. 이전 작업을 되풀이하지 않는다.

후속 문서는 **보관용 검토안**이다. 문서 작성 승인과 모든 기능 구현 승인은 다르다. 확인되지 않은 CLI 필드·정책·권리·인프라는 조건으로 남기고 임의의 계약을 만들지 않는다. 각 묶음은 착수 전 해당 설계/계획만 갱신·검토한다.

## 진행 규칙

- 한 번에 한 구현 묶음. 미래 아이디어로 완료한 기능을 다시 구현하지 않는다.
- 기능별 완료/부분/보류와 시험 범위를 기록한다. 합성 시험을 실제 게임/계정 검증으로 표현하지 않는다.
- 관련 좁은 회귀를 먼저 수행하고 묶음 완료 때 타입·통합·빌드를 수행한다. 관련 없는 전체 조사와 전체 시험을 매 단계 반복하지 않는다.
- 새 게임 행동·권한/DB·외부 노출·배포는 승인 경계를 유지한다. 실패한 행동을 자동 재실행하지 않는다.
