## 화면 확인 제한

컴퓨터 사용 도구의 창 목록에 IRIS가 반환되지 않아 실제 앱 조작을 직접 관찰하지 못했다. 이후 사용자가 제공한 스크린샷으로 실제 창·로그인·숙제 연동·테마 전환을 확인했다. 일반 브라우저 `/iris/desktop`의 전용 앱 안내는 확인했고, 일반 브라우저에서 편집을 막는 기존 동작을 보존했다. 비밀번호/로그인 코드는 도구로 입력하지 않는다. 스탯과 시낙시스 탭은 미지원 안내 상태이며 연결 완료가 아니다.
