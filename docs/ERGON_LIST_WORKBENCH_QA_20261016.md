## Rulings I made (시간순)

1. 기존 feature checkout에서 진행: 현재 폴더·개인 dirty 보존과 기존 앱 개발 경로를 재사용했다. 잘못 판단했을 때 비용은 관련 변경이 같은 checkout을 공유하는 것이라 명시적 파일만 stage했다.
2. `useErgonSession`에 동기 plan scope mask 추가: 실제 flushSync 전환에서 이전 계정 행이 잠깐 보였다. 잘못 판단했을 때 비용은 전환 중 짧은 빈/로딩 화면이며 관측자 remount는 하지 않는다.
3. 목록에 알려진 횟수/날개 예상 한 줄 유지: 중복 편집기 제거로 기존 비용 정보가 사라지는 것을 막았다. 잘못 판단했을 때 비용은 예상이 실제로 오해되는 것이라 예상/최소/상한 미확인을 명시한다.
4. 준비취소 pause 동기 해제·확인 중 수량 고정: 부모 보호가 취소 직후 편집을 누락시키고 확인 입력이 열려 있던 실제 회귀를 해결했다. 잘못 판단했을 때 비용은 잠깐의 조회/편집 정지이며 native 동의 범위는 바꾸지 않는다.
5. 최종 리뷰 기준은07b3f4f..42c6b96: 재사용 장기 브랜치의 이 기능 이전 이력은 이번 계획 구현이 아니다. 잘못 판단했을 때 비용은 과거 결함 잔존이므로 기존 전체 회귀/native smoke와 별도 실제 게임 검증을 유지한다.
