2. 길드버스 구성을 정원과 대기 순서에 맞게 다듬었습니다.
   첫 구성부터 재구성, 다음 회차까지 4인·8인 정원에 맞는 전투력 등급 분배를 적용합니다. 같은 계정의 여러 캐릭터가 동시에 출전하지 않도록 하고, 참가 시간·완료 상태·대기 순서를 함께 반영해요. 가능한 참가자 안에서 정원을 채우며, 특정 등급의 인원이 부족하면 다른 참가자로 보완합니다.

3. 콘텐츠마다 실제 등록된 난이도만 선택할 수 있습니다.
   레이드 선택에 어비스 난이도가 섞여 보이던 문제를 수정하고, 선택한 난이도에 맞는 정원을 사용하도록 했습니다.

4. 크로노스의 다른 완료 기록을 보존하도록 저장 흐름을 보완했습니다.
   파티 완료를 기록하거나 다른 화면에서 숙제를 변경할 때, 기존의 다른 완료 항목이 사라지지 않도록 개선했습니다. 홈의 체크 해제와 연속 저장도 함께 다듬었어요. 다만 이미 사라진 과거 기록을 자동으로 되살리는 업데이트는 아니므로, 이전 기록에 이상이 있었다면 운영진에게 알려 주세요.
